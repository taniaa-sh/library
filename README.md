# Library App

This is library-App for the Ministry of Economy and Finance. The App aims to manage users, monitor user information, handle roles, track and manage assets, seeing detailed reports and other administrative features.

<h2>Built with</h2>
<ul>
   <li>Programming Language ┈➤ TypeScript</li>
   <li>JavaScript Framework? ┈➤ NextJs</i>
   <li>Styling ┈➤ TailwindCss</li>
   <li>BackEnd ┈➤ C# | .Net</i>
</ul>

<h2> Development setup</h2>
<p>1. First, you need to clone the project:</p>

```
git@gitlab.hoshmand.local:root/amin-front.git
```

<p>2. Then, install required packages:</p>

```
npm i
```

<p>3. Finally, run the <code>dev</code> script to start the dev server:</p>

```
npm run dev
```
